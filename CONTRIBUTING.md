# Contributing

Bug reports, tests against more printer models and slicer updates
(see [docs/updating.md](docs/updating.md)) are welcome.

Hard rules, to keep this project clean and legal:

- **No code, binaries, keys or certificates from Bambu Lab's closed-source
  software** (plugins, firmware, Bambu Connect, Bambu Handy…), and nothing
  obtained by decompiling or disassembling them. Work from the slicers'
  open-source code and from public protocol documentation.
- **No circumvention**: no command signing with extracted keys, no firmware
  authorization bypass, no Bambu cloud login/impersonation. LAN only, with the
  owner's access code.
- **No Bambu Lab logos or branding**; product names only to describe
  compatibility.
- Never commit personal data (printer serials, access codes, IPs, account IDs).
  Tests use placeholders.

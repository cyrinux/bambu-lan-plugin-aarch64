Native aarch64 LAN plugin for **Bambu Studio 2.9.x** (flatpak or native), tested with a Bambu Lab A1.

Install: close Bambu Studio, extract the tarball, run `./install.sh` (`--native` for a non-flatpak Studio, `--uninstall` to restore Bambu's files).

See the README for supported printers and features. LAN only: no Bambu cloud, no SD-card file browser.
